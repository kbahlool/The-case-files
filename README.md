# The Case Files
Run: `npm install && npm run dev` · Build: `npm run build` (deploy `dist/` to Vercel) · Check content: `npm run validate`
Add a case: create `src/cases/case002/` (copy the case001 file layout), export one object, add an entry in `src/cases/index.js`.
Art: drop files into `public/assets/case001/{scenes,characters,...}` (see public/assets/README.txt). Missing files fall back to procedural art.
